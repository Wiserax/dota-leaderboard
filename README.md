# Dota 2 Leaderboard — Europe, с изменениями позиций

Лидерборд Европы с отметками, куда каждый игрок поднялся/опустился с момента вайпа рейтинга (патч 7.41e, 31 июля 2026: MMR Immortal сжат до ≤9500 с сохранением порядка мест).

- `index.html` — страница (RU/EN), открывается локально или с GitHub Pages
- `data.js` — слитые данные: текущие места + дельты относительно стартовой базы
- `baseline_pre_reset.json` — стартовый лидерборд: самый ранний доступный слепок после вайпа (31 июля, 11:13 UTC, из Wayback Machine; так как патч сохранил порядок мест, это же и финальный порядок до вайпа)
- `build.py` — тянет свежий лидерборд с API Доты и пересобирает `data.js`
- `.github/workflows/update-data.yml` — автообновление данных раз в час на GitHub Actions

Обновить вручную: `python build.py` (или `python build.py --offline` без сети).

«—» у игрока значит, что разницу посчитать не удалось: на стартовом лидерборде он был под другим ником либо отсутствовал — API отдаёт только ники, без ID аккаунтов, переименованных сопоставить нельзя.
