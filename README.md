# Dota 2 Leaderboard — Europe, с изменениями позиций

Лидерборд Европы с отметками, куда каждый игрок поднялся/опустился с момента сброса рейтинга (патч 31 июля 2026).

- `index.html` — страница (RU/EN), открывается локально или с GitHub Pages
- `data.js` — слитые данные: текущие места + дельты относительно базы до сброса
- `baseline_pre_reset.json` — последнее состояние лидерборда до сброса (31 июля, 11:13 UTC, из Wayback Machine)
- `build.py` — тянет свежий лидерборд с API Доты и пересобирает `data.js`
- `.github/workflows/update-data.yml` — автообновление данных раз в час на GitHub Actions

Обновить вручную: `python build.py` (или `python build.py --offline` без сети).

NEW у игрока значит, что ника не было на борде до сброса: новичок либо сменил ник — API отдаёт только ники, без ID аккаунтов, переименованных сопоставить нельзя.
